
# 📶 Network Status Checker (Kotlin)

A simple Android app built with **Kotlin** that checks your current **network connectivity status**.  
It detects whether your device is connected to the internet (via Wi-Fi or mobile data) and displays a message accordingly.

---

## 🧩 Features

- ✅ Detects network connection in real time  
- 📡 Differentiates between Wi-Fi and Mobile Data  
- ⚠️ Displays a clear message when offline  
- 🧱 Built using modern **Kotlin** and **Android Jetpack components**
